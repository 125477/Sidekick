# 灵伴 v1.1.0

桌面陪伴小精灵：智能体陪伴短句、情绪日记（今日小结 / 历史）、换肤与形象、每日抽签、收藏历史；本版起支持**应用内检查更新**（GitHub Releases）。

---

## 下载

| 系统 | 文件 | 说明 |
|------|------|------|
| **macOS** | `Lingban-1.1.0-arm64.dmg` | 安装后应用名仍为「灵伴」；新用户**首次安装**用 |
| **macOS（自动更新）** | `Lingban-1.1.0-arm64-mac.zip` + `latest-mac.yml` + 同名 `.zip.blockmap` | 已安装用户由应用内更新拉取；**勿用中文文件名**（GitHub 会截断） |
| **Windows** | `Lingban-Setup-1.1.0.exe`（x64） | 新用户安装 |
| **Windows（自动更新）** | 同上 `.exe` + `latest.yml` + `.exe.blockmap` | 须一并上传 |

> 维护者：只上传 dmg 时，老用户**无法**在应用内完成更新。详见 [RELEASE.md](./RELEASE.md)。

---

## 使用说明

1. 安装后从启动台 / 应用程序打开「灵伴」。
2. 首次使用可在设置中配置陪伴语气、推送间隔等；若使用云端生成，需在设置中填写 **DashScope API Key**（仅保存在本机）。
3. 拖动精灵可换位置；设置中开启「劲动」后，拖动会留下星星拖尾。
4. **已安装 v1.0.x**：启动约 12 秒后会自动检查更新，也可在 **设置 → 通用 → 版本更新** 手动检查；下载完成后按提示重启安装。

## 本版主要能力

- 桌面透明挂件 + 独立陪伴气泡窗。
- **陪伴智能体**（百炼，可选）：定时推送、换一句、情绪反馈后、昨日续接、解锁屏幕、专注结束、保存小结收束、连续记录鼓励、兴趣深化等；轻反馈「喜欢 / 一般 / 少推」会越点越像你。
- **情绪**：此刻记录、今日小结（引导提问 / 润色 / 保存后收束）、本地趋势图；历史详情公众号式排版，小结支持多种**文案气泡**样式。
- **设置 → 文案展示 → 气泡样式**：陪伴气泡与历史小结可切换展示样式（预览后生效）。
- 换肤：内置 Lottie / 图 / 视频，支持上传 GIF / MP4。
- 每日抽签、收藏历史、勿扰 / 专注 / 推送时段。
- 拖动星星拖尾（独立 overlay 小窗）。
- **应用内更新**：`electron-updater`，对接 GitHub `125477/Sidekick` Releases。

## 相对 v1.0.0 的更新摘要

- 新增 **应用内检查更新 + 后台下载**（设置 → 通用 → 版本更新）。
- 陪伴场景扩展（解锁、专注结束、日记收束、连续记录、兴趣深化等 trigger）。
- 今日小结 / 历史记录详情 UI 改版；多种日记文案气泡；设置里可选气泡样式。
- 拖动拖尾改为屏幕坐标 + 独立拖尾小窗；性能优化（帧率、粒子上限等）。
- 面板背景透明度、情绪趋势图等 V1.1 相关界面完善。
