## 长版（帖子 / 介绍）

# 我在桌面养了一颗会说话的小星星 ✨

## 我是谁

如果你不想再多一个「催你变高效」的工具，只想在加班或发呆时，角落里有个小家伙轻轻说上一句人话——**灵伴（Sidekick）** 就是为此做的 **Electron 桌面挂件**：

- **透明窗**贴在屏幕一角，拖动星星即可换位置（带星星拖尾小动效）
- **陪伴气泡**：一条短中文，不聊天、不刷屏；可**换一句**、复制、收藏、语音播报
- **智能体陪伴**（可选百炼 / 通义）：按语气、兴趣、情绪与轻反馈写句；定时推送、情绪反馈后、昨日续接、解锁屏幕、专注结束、保存小结收束、连续记录鼓励、每日兴趣小问句等——都仍是**一条气泡**，不是对话框
- **情绪**：记录「此刻」｜写「今日小结」，本地看趋势（**不上传云端**）
- **今日小结助手**：3 条写日记引导问、正文润色、保存后自动生成一句收束
- **换肤**：内置 Lottie / 图 / 视频，也支持自己上传 GIF / MP4
- **勿扰 / 专注 / 推送时段**：该安静时不会硬推

**macOS / Windows** 安装包在 [GitHub Releases](https://github.com/125477/Sidekick/releases/latest)，**开源**（PolyForm Noncommercial）。

如果你也喜欢「**被看见一下，而不是被安排一下**」，有 bug 或想法欢迎提 [Issue](https://github.com/125477/Sidekick/issues)，我会看。

## 智能体版本（更新 / Release 正文）

# 灵伴更新：角落的小星星，开始「懂你一点」地说 ✨

以前灵伴会在气泡里陪你说句话；这一版把**陪伴、日记、生活节奏**接进了智能体——仍然是**一条短句、一个小气泡**，不变成聊天框，也不催你变高效。

### 你会感受到什么

**① 陪伴更贴你**  
定时推送、点「换一句」、选完「此刻」情绪之后，都由**陪伴智能体**按你的语气、兴趣、心情来写 10–32 字的短句。对句子点 **喜欢 / 一般 / 少推这类**，它会记住偏好——**越点越像你**。

**② 日记不只会存，还会接住你**  
写「今日小结」时，可以要 **3 条温柔的写日记引导问**，也可以 **润色** 草稿；**保存后**会多一句**收束陪伴**，像把今天轻轻合上。连续记满 3 / 7 / 14 天，偶尔会收到一句不夸张的鼓励。

**③ 生活在关键节点被看见**  
有昨日心情或日记时，**当天第一次打开**或**从休眠回来**可能有一句昨日续接；**解锁屏幕**、**专注结束**时，也可能各来一句情境问候（遵守你设的推送时段、勿扰和专注，不硬刷屏）。每天还有少量**兴趣小问句**，帮你把偏好慢慢写进陪伴里。

**④ 仍然是你桌面上的那颗星**  
透明挂件、拖动换位置、收藏与朗读、换肤（含 GIF / 视频）、本地情绪趋势、每日抽签——都在。情绪与日记**只在本机**，不上传云端。

### 适合谁

不想多一个「管家 App」，只想在加班、发呆或刚写完日记时，被**看见一下，而不是被安排一下**的人。

### 下载

macOS / Windows：[GitHub Releases 最新版](https://github.com/125477/Sidekick/releases/latest)  
使用智能体需在设置中配置百炼 / 通义（见仓库说明）；未配置时会自动用本地备用句，不影响挂件使用。

有想法或 bug，欢迎 [Issue](https://github.com/125477/Sidekick/issues)。
