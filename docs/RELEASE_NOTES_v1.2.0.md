# GitHub Release 正文（v1.2.0）

## 正文（复制以下全部）

- **右缘贴边半露**：勿扰/拖到右缘可半隐藏精灵；**非勿扰**下主动推送会先滑出完整形象，展示 **15 秒**（可在 **设置 → 文案展示 → 贴边推送展示** 调 10–30 秒）后随气泡关闭缩回半露。左/上/下缘受 macOS/Windows 工作区限制，不做吸附。
- **兴趣深化闭环**：每日兴趣问句（`interest-deepen`）推送时 hover 展示输入框，提交后写入本地兴趣偏好，后续生成会参考。
- **收藏句偶尔再现**（设置可关）：定时/情境推送约 20% 概率 resurfacing 一条收藏句。
- **今日小结连续天数**：情绪反馈 → 今日小结页趋势图上方显示「已连续 N 天」徽章。
- **陪伴卡片导出**：气泡工具栏「导出」替代复制；独立面板可选多种气泡样式、编辑文案、导出 PNG。
- **全局快捷键**：`⌘⇧R` / Ctrl+Shift+R 换一句；`⌘⇧E` / Ctrl+Shift+E 打开今日小结；`⌘⇧C` / Ctrl+Shift+C 导出卡片（**设置 → 通用** 可查看说明）。
- **开机恢复**：重启后恢复精灵窗口位置；若上次为右缘半露或勿扰锁，会自动恢复。

**已安装 v1.1.x**：启动约 12 秒后可应用内检查更新（**设置 → 通用 → 版本更新**），或从下方 Assets 手动下载。
