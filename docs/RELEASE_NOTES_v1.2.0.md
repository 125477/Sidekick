# 灵伴 v1.2.0

桌面陪伴小精灵：贴边推送体验、兴趣深化闭环、收藏再现、卡片导出、全局快捷键与状态恢复。

---

## 本版主要能力

### 贴边与推送

- **贴边推送展示时长可配置**（设置 → 文案展示 → 10–30 秒，默认 15 秒）：精灵右缘半露时，主动推送会滑出完整形象，展示设定时长后随气泡关闭缩回半露。
- **开机恢复位置与吸附态**：重启后恢复窗口坐标；若上次为右缘半露/勿扰锁，会自动恢复（写入 `userData/widget-bounds.json`）。

### 陪伴与兴趣

- **兴趣深化闭环**：气泡 hover 显示「点击输入」，可补充兴趣/状态，写入本地兴趣偏好供后续生成参考。
- **收藏句偶尔再现**（设置可关）：定时/情境推送约 20% 概率 resurfacing 一条收藏句。

### 情绪日记

- **小结连续天数可视化**：今日小结页趋势图上方显示「已连续 N 天」徽章。

### 导出与快捷键

- **陪伴卡片导出**：工具栏「导出」替代复制；独立面板可选多种气泡样式、编辑文案、导出 PNG。
- **全局快捷键**（设置 → 通用可查看）：
  - `⌘⇧R` / Ctrl+Shift+R：换一句
  - `⌘⇧E` / Ctrl+Shift+E：打开今日小结
  - `⌘⇧C` / Ctrl+Shift+C：导出当前陪伴卡片

### 其他

- 自启动（`launchAtLogin`）与位置恢复配合；打包版登录时启动仍依赖系统「登录项」权限。

## 相对 v1.1.0

- 新增贴边推送停留、兴趣输入、收藏再现、streak 徽章、卡片导出、全局快捷键、吸附/勿扰状态恢复。
- 右缘吸附仍仅支持 macOS/Windows **workArea 右缘**（左/上/下受系统安全边距限制，不吸附）。
